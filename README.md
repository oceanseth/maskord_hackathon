Maskord is a replacement for discord, with true end to end encryption and anonimity.
Even in voice channels with many users, the data cannot be read by anyone in the middle, even if they were able to spy on it, but it is only sent between people 'on the call'.
Given this feature, maskord also provides the ability to speak or be seen using avatars from masky.ai, so you can wear whatever mask you wish when interacting with others.
